# create-tact

> [!CAUTION]
> Deprecated. Use [Acton](https://ton-blockchain.github.io/acton/) instead.

Creates Tact project from template

## Prerequisites

- node.js
- npm
- git

## How to use

Use `create` of your favorite package manager to run:

```shell
npm create tact@latest
```

or

```shell
yarn create tact@latest
```
